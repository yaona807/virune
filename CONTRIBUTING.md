# Contributing to Virune

日本語: [CONTRIBUTING_ja.md](CONTRIBUTING_ja.md)

Contributions to Virune are welcome.

## Getting started

You can contribute by reporting bugs, proposing features, improving documentation, or submitting code changes.

See the [Code of Conduct](CODE_OF_CONDUCT.md) for community conduct.

If you find a security issue, do not open a public Issue. Follow the [Security Policy](SECURITY.md).

## Issues

Small fixes may be submitted directly as Pull Requests without opening an Issue first.

For larger features or design changes, discuss the change in an Issue before starting implementation.

For changes to the language specification, public APIs or ABIs, or compatibility, open an Issue before implementation.

## Development

Start work from the current `main` branch.

Keep each Pull Request focused on one purpose and avoid unrelated changes.

When changing behavior, add or update tests that cover the change.

Build and test commands are defined in `package.json`.

## Pull Requests

Briefly describe what the Pull Request changes and why.

Link a related Issue when one exists.

Use a Draft Pull Request while the work is still in progress.

## Questions

If you are unsure about a proposed change or how to contribute, open an Issue and ask.
