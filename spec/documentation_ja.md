# ドキュメントコメント

[英語版](documentation.md)

## `[documentation.kinds]` コメントの種類

Viruneでは、3種類の行コメントを区別します。

```virune
// 通常コメント
/// 直後の宣言を説明するドキュメントコメント
//! 現在のソースモジュールを説明するドキュメントコメント
```

`///`は、スラッシュが正確に3個並び、その直後が`/`以外の場合にだけドキュメントコメントとして扱います。`////`は通常の行コメントです。

## `[documentation.module]` モジュールドキュメント

連続した`//!`行のグループは、現在のソースモジュールを説明します。ファイルの先頭に置き、`import`、属性、宣言、ほかのコメントより前に記述しなければなりません。先頭の空白と空行は許可します。1つのソースモジュールに記述できるモジュールドキュメントのグループは1つだけです。

## `[documentation.declaration]` 宣言ドキュメント

連続した`///`行のグループは、直後にある、ドキュメントコメントに対応している宣言を説明します。`///`は、各行で最初の空白以外の内容でなければなりません。コメントグループと宣言の間には、空行や宣言の属性を記述できます。通常コメントまたはほかのトークンがあると、宣言との関連付けは終了します。

ドキュメントコメントを付けられる対象は以下です。

- 関数
- `record`とそのフィールド
- `enum`とそのバリアント
- `newtype`と型エイリアス
- トップレベルの`let`と`const`宣言
- `extern`ブロックと`extern`関数

`import`、テスト、パラメーター、ローカル変数、文、式には付けられません。どの宣言にも関連付けられていないドキュメントコメントや、対応していない構文に付けられたドキュメントコメントはコンパイルエラーです。

## `[documentation.normalization]` 本文の正規化

各行からマーカーを取り除き、その直後にASCIIスペースがある場合は最大1文字だけ取り除きます。残りの行をLFで連結し、先頭と末尾にある空のドキュメント行を取り除きます。

## `[documentation.markdown]` Markdown

本文はCommonMark 0.31.2互換のMarkdownです。公式ツールは生のHTMLを描画しません。

## `[documentation.semantics]` コンパイル時の意味

ドキュメントは、名前解決、型検査、JavaScript出力、Runtime ABIには影響しません。

## `[documentation.diagnostics]` 診断

| コード | 条件 |
|---|---|
| `L0010` | `///`グループが対応している宣言へ関連付けられていない。 |
| `L0011` | `//!`グループがファイル先頭にない。 |
| `L0012` | `///`グループの対象が対応していない構文である。 |
| `L0013` | モジュールまたは宣言に複数のドキュメントグループがある。 |
