# Virune Code of Conduct

日本語: [CODE_OF_CONDUCT_ja.md](CODE_OF_CONDUCT_ja.md)

Virune adopts the behavioral standards of [Contributor Covenant 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/).

This Code of Conduct applies to project interactions such as Virune Issues, Pull Requests, and reviews.

Technical disagreement is acceptable. Criticism should address code, design, evidence, or process rather than attacking a person or group.

## Reporting a conduct concern

Do not put conduct-incident details or personal information in a public Issue.

Virune currently has only one maintainer, so there is no other Virune representative to whom concerns about the maintainer can be reported. For conduct that violates GitHub policies, use GitHub's reporting tools.

Report security issues according to [SECURITY.md](SECURITY.md).
