# Virune Project Governance

日本語: [GOVERNANCE_ja.md](GOVERNANCE_ja.md)

## Governance

Virune is currently an open-source project maintained by [`@yaona807`](https://github.com/yaona807).

There is currently no steering committee or voting process.

## Maintainer responsibilities

The maintainer is responsible for Virune's overall operation, including project direction, Issues and Pull Requests, releases, and security response.

See [CONTRIBUTING.md](CONTRIBUTING.md) for how to contribute, [SECURITY.md](SECURITY.md) for reporting security issues, and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for community conduct.

## Decision making

Changes and proposals are generally developed in public through Issues and Pull Requests.

The maintainer makes the final decisions.

## Changing this document

Changes to project governance are made publicly through Issues or Pull Requests.

`GOVERNANCE.md` and `GOVERNANCE_ja.md` are updated together in the same Pull Request.
